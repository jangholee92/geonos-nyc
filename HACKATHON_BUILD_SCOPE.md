# Hackathon build scope

GEONOS was developed in a private working repository during the hackathon. This public repository is a sanitized source snapshot of commit `fd667567f782f37df64358d4c90554ee99a35c84`; its initial public commit is an export, not a reconstruction of the private development history.

## Work built for this project

- The one-viewport NYC map, native-building selection and automatic two-place evidence comparison.
- Citywide source acquisition/join validation, static footprint tiles and bounded public-source adapters; explicit separation of building, tax-lot and community measurements.
- Requirement evaluation, missing-evidence logic, source-linked receipts, energy reporting-scope analysis and climate context preparation.
- Spark tool orchestration, transparent refusal handling, SAM aerial evidence and map/mask crosscheck, Wonder reviews, Image inspection concepts, editable Voice drafts and the browser DINOv2 comparison workflow.
- Application-specific tests, source/QC/provenance checks, bounded transports, cancellation/state guards and browser validation.

These claims describe integration, code and derived products—not ownership of government observations, development of the foundation models, or training a new change detector.

## Pre-existing foundations

- Meta's Muse/SAM APIs, official SAM parser, and pretrained DINOv2 weights. GEONOS did not train these models.
- NYC/NYS/NOAA/Census/MTA public-source measurements, imagery and boundaries. GEONOS acquired, validated, transformed or queried them; it did not collect the original government observations.
- Sites/Vinext/Next/React, Cloudflare development tooling, MapLibre, ONNX Runtime, UI libraries and other locked dependencies. Their licenses and attribution remain separate.
- Published scientific methods and papers cited in the reports. Application-specific calculations and visualization do not establish independent scientific validation.
